# ASE 2025 Materials

Conference presentation materials for **PALM: Synergizing Program Analysis and LLMs to Enhance Rust Unit Test Coverage**.

- [Poster](research-2647-poster.pdf): one A0 page.
- [Presentation](research-2647-pre.pdf): 33 pages.

This repository copy updates the poster's materials QR code to this page and adds acceptance-rate denominator notes to the poster and slides 28 and 32. The experimental figures remain unchanged; the materials describe the paper's experiments, not a new evaluation of the current implementation.

The reported acceptance rate is **80 / (80 + 5) = 94.1%**, among submissions with a decision at the time of the paper. Of 91 submitted tests, 80 were accepted, 5 were rejected, and 6 were pending; the pending submissions are excluded from that rate. See the [paper](https://arxiv.org/abs/2506.09002) for the study and its scope.

For installation and commands for the current code, see the [project README](../../README.md) and [technical guide](../palm-rust-unit-test-generation.md).
