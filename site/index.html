Start small.
See the whole pipeline.

The minimal example checks analysis, generation, compilation repair, execution, coverage, and source restoration. No model credentials needed.

First install the prerequisites: Git, Rust and a C linker, Python 3.9+, the pinned nightly, and cargo-llvm-cov. Downloads may need network access.

Run from your terminal 
git clone https://github.com/cppbear/PALM.git
cd PALM
cargo build --workspace --locked
python3 scripts/check_minimal.py

Expected completion

Minimal analysis/generation/repair/coverage checks passed.

Ready for your own package?

Install the tools, configure a model, and begin with a small function list and request budget. Preprocessing changes source and tests, so use a fresh working copy.

Know where it fits.

Start with one standalone Cargo package and a few functions. Expand after checking the results.

Unit & integration tests
Unit tests use the recorded library or binary target. Function-level integration tests require a library and check external access.
One package at a time
Ordinary lib/bin targets are supported, including custom names and entry files. The complete workflow does not support multi-package workspaces.
Explicit analysis boundaries
Analysis follows the active build configuration. Definitions shared by lib and bin prefer lib; this does not cover every binary variant.
A pinned Rust toolchain
Uses nightly-2025-03-19 and cargo-llvm-cov 0.6.16. Linux CI and local macOS Apple Silicon have been exercised; Windows has not been validated.
