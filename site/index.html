Run the minimal fixture through analysis, generation, repair, execution, and coverage. No model credentials needed.

First install the prerequisites: Git, Rust and a C linker, Python 3.9+, the pinned nightly, and cargo-llvm-cov. Downloads may need network access.

Run from your terminal 
git clone https://github.com/cppbear/PALM.git
cd PALM
cargo build --workspace --locked
python3 scripts/check_minimal.py

Full scope and limitations
One Cargo package
Ordinary lib/bin targets, including custom names and entry files. The complete workflow does not support multi-package workspaces.
Unit & integration tests
Unit tests use the recorded target. Function-level integration tests require a library and check external access.
The active build configuration
Shared lib/bin definitions prefer lib. Analysis does not explore every binary variant or feature combination.
Pinned tools
nightly-2025-03-19 and cargo-llvm-cov 0.6.16. Exercised on Linux CI and macOS Apple Silicon; Windows has not been validated.

Built on research.
Open for exploration.
